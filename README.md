This is an NES emulator created for the MIT FPGA class 6.205 (Digital System Laboratory) in Fall of 2025.

This was created in a group of 3.

This project unfortunately is not working end to end, but the part I was responsible for (the PPU) produces a working frame with background rendering given the correct preloaded memory!

See the generate_ppu_img.py file and convert_dump.py file on how to create that.

This was really fun and while I don't have an FPGA of my own right now, I'd like to continue this and finish it either continueing on an FPGA or doing this in C++ instead, but I'll decide once we get there!
